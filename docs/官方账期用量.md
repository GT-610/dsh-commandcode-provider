# 官方账期用量

## 一、实现与范围

1. 官方来源为 `GET /alpha/whoami`（账号）、`GET /alpha/billing/credits`（余额）、`GET /alpha/billing/subscriptions`（订阅）和 `GET /alpha/usage/summary`（用量汇总）。按官方 `command-code@1.82.1` 的实际调用顺序，先捕获组织，再并行读取余额和订阅，最后给汇总传入同一 `orgId`（组织标识）及订阅原始 `currentPeriodStart`（账期起点）作为 `since`（统计起点）。仅编码参数，不转成本地自然月。
2. 订阅失败、缺失或无效起点时，汇总继续独立读取，不补起点。报告仅保留服务端实际返回的 `periodStart`（统计起点）；未上报 `periodBasis`（统计口径）不再默认成账期。两个新增起点字段在严格远端上可选，兼容旧宿主报告。
3. 设置页和额度面板只有在汇总起点与订阅起点相同、截止时间有效时展示完整账期。旧宿主、缺失或不一致时，额度面板显示中文“统计周期未确认”，设置页改显订阅自身的“账期截止”日期。请求数采用 `totalCount`（请求总数），成功与失败另列；命令入口沿用同一总数。
4. 官网用量页三条实际查询均使用 `credentials: "include"`（携带浏览器登录会话）。同一真实账号的既有密钥在官方汇总接口成功，在三条网页明细接口返回 401。未接入浏览器会话、未保存网页凭据或实际账单内容。官方汇总额是模型/工具用量扣费，不代表订阅费、充值或发票；现有会话分析仍按当前价格重算。
